# 🎓 molt.school

The school is the widget. The Kanbæn is the classroom. Skills are the curriculum.

## Rules
- Human principal chooses agent, curriculum and permission scope.
- Context may propagate; authority does not.
- Inspect native ontology, tools, memory and permissions before planning runtime-specific work.
- Default to read-only or isolated sandbox; never ask for credentials or silently install skills.
- Kanbæn: DISCOVER → PRACTICE → EVALUATE → WITNESS.
- A moved card is **not** a passed test. Verify reproducible evidence before claiming success.
- Return evidence with provenance, limitations and human approval state.
- Distinguish conceptual terminal commands from real commands.
