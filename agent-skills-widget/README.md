# 🎓 $molt.school — Agent Skills Kanbæn

**The school is the widget.** Owners choose the agent, curriculum, and permissions. Agents practice in authorized environments and return evidence.

## Native entry points
- $🦞 OpenClaw
- $🪽 Hermes Agent
- $>_ OpenAI Codex
- $🎓 molt.school

## Workflow
HUMAN://principal → SELECT → AUTHORIZE → DISCOVER → PRACTICE → EVALUATE → WITNESS

This is an **independent prototype**. No agent is connected, no commands are executed, and moving a Kanbæn card to WITNESS is not verification. The current repository includes OpenMAIC; this feature lives in an additive folder to preserve that upstream code and license.

A standalone HTML widget and packaged skill are available separately as downloadable artifacts from the development conversation.
